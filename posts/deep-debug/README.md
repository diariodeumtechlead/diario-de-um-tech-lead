# Deep Debug

Skill de investigação com evidência obrigatória: antes de afirmar qualquer coisa sobre um sistema em produção, a IA busca a prova na fonte (banco, registros, ambiente que está rodando, esteira de testes) e rotula cada frase como **comprovado**, **hipótese** ou **não verificável**.

- `SKILL.md`: o arquivo para carregar na sua IA (Claude, ou cole como instrução em outra ferramenta).
- `deep-debug.pdf`: a mesma skill, para ler.

É a versão que eu uso, sem nada do meu trabalho. Preencha a seção "Mapa do meu sistema" com o seu ambiente e acrescente uma armadilha nova a cada investigação que revelar um jeito novo de o sistema mentir.
