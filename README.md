# Diário de um Tech Lead

Bastidor real de liderança técnica: o que deu errado, o que eu tentei e o que eu mudei depois.

Aqui fica o material que acompanha os vídeos e os posts: código, skills e modelos para baixar e adaptar. Cada pasta em `posts/` é um episódio.

| Pasta | O que tem |
|---|---|
| [`posts/a-curva-que-mentiu`](posts/a-curva-que-mentiu) | Um modelo de previsão de salário que roda, desenha uma curva bonita e está errado. A correção de uma linha, o backtest e as três perguntas antes de levar um gráfico de tendência para a reunião. Python, dados fictícios. |
| [`posts/deep-debug`](posts/deep-debug) | A skill que obriga a IA a mostrar a prova antes de afirmar qualquer coisa num incidente. |

Os dados dos exemplos são fictícios. Nada aqui vem de sistema, empresa ou cliente real.
